## Судьба каждого ограничения v3

### I.1 Gradle/GameTest/client/server/visual раннеры не исполнены — **ОСТАЛОСЬ** (BLOCKED)
Причина неизменна: 4 ГБ cgroup, нет Docker/GPU; NeoForm требует >=8 ГБ.
Что сделано v4: runner-инфраструктура не тронута; добавлен недостающий
компонент — задачи для GameTest (см. I.6). Честный статус сохранён: L3–L6 = N/A.

### I.2 private_eval публикуется как held-out-файл — **ЗАКРЫТО**
v4 исключил `private_eval.jsonl` из публичного бандла; файл публикуется только
в приватном репозитории `ComerX/forgebench-v4-private` (учётные данные владельца).
README v3-конфиг private_eval удалён из карточки.

### I.3 Контаминация против SFT-корпуса NOT_RUN — **ЗАКРЫТО (ИЗМЕРЕНО)**
Измерено против SFT-v2.1.0-rc2/train (7422 записи) и CPT-v9-full (12620 записей):
containment >= 0.10 у 224/411 задач (максимум 0.51) — идиоматика; непрерывные
пробеги: max 39 шинглов против SFT (import-блок), 44 против CPT (import-блок/
литералы); 4 автоматических подозрения реклассифицированы вручную как boilerplate
со сниппетами. Дословной утечки задач нет. Скрипты: stage5*, сниппеты в runs_top.jsonl.

### I.4 Groovy/Kotlin DSL token-level — **ЗАФИКСИРОВАНО + ЧАСТИЧНО УСИЛЕНО**
Парсер DSL в среде отсутствует (документация: docs/dsl_limitations.md). Усиление:
DSL-эталоны прошли класс-уровневый API-evidence гейт; версии платформ сверены
с pinned-артефактами. Полная семантика — только через L3 (BLOCKED).

### I.5 Современный профиль 1.21.9+/26.x только каркас — **ОСТАЛОСЬ** (по плану)
Не воспроизводим в среде; изменение не заявлялось.

### I.6 GameTest-задач нет — **ЗАКРЫТО**
Добавлено 10 задач GT_001..GT_010 (8 NeoForge + 2 Forge; synthetic=true):
регистрация (@GameTestHolder/@PrefixGameTestTemplate — сверены по исходникам),
assertions, тайминги, батчи, негативные проверки. Все константы/методы
само-проверены по маппингам; API-проверка задач: 57/57 class_exists.
Исполнение тестов — NOT_RUN (см. I.1) — честно отражено в поле
verification_status и метриках.

## Остаточные ограничения (для следующей версии)

1. L3–L6 исполнение — нужен хост >=8–16 ГБ / Docker (не устраняем в этой среде).
2. DSL-парсер (Groovy/Kotlin) — требует toolchain или L3.
3. МинХэш near-dup перепроверка пула v4 (exact-скан чист; 22 v3-пары семейных).
4. Продвижение GT-задач в public/private сплиты — следующее версионирование.
5. Ротация HF-токена сразу после публикации (токен светился в чате).
